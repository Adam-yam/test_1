# SCENE Studio

사진 한 장으로 음악 포스터와 초점·셔터 애니메이션을 만드는 정적 웹 편집기입니다. 페이지와 결과물 디자인을 새로 작성했으며, 원본 프로젝트의 HTML/CSS/JavaScript·이미지·로고를 복사하지 않았습니다.

## GitHub Pages에 올리기 — 가장 간단한 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 ZIP을 **압축 해제**하고 `index.html`, `styles.css`, `app.js`, `vendor` 폴더를 저장소의 **최상위**에 올립니다. ZIP 파일 자체를 올리면 실행되지 않습니다.
3. 저장소 **Settings → Pages → Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
4. Branch를 **main**, 폴더를 **/(root)**로 선택하고 Save를 누릅니다.
5. 배포 완료 후 Pages에 표시되는 주소로 접속합니다. `https://계정명.github.io/저장소명/` 형태의 하위 경로도 지원합니다.

별도 빌드, npm 설치, API 키, 서버 설정이 필요 없습니다. `vendor` 폴더가 누락되면 GIF 생성이 작동하지 않습니다.

### GitHub Actions 배포를 원하는 경우

`.github/workflows/pages.yml`까지 포함해 업로드한 뒤, **Settings → Pages → Source → GitHub Actions**를 선택합니다. main 브랜치에 푸시하거나 **Actions → Deploy SCENE Studio → Run workflow**로 배포합니다. 기본 브랜치가 main이 아니면 workflow의 branches를 변경합니다. 두 배포 방식 중 하나만 선택하세요.

## 사용법

- 사진 선택, 드래그 앤 드롭 또는 클립보드 붙여넣기로 사진을 불러옵니다.
- **뮤직 포스터**: 곡명·아티스트·시간을 입력하고 배경색과 출력 크기를 선택합니다. 다섯 가지 색은 사진에서 자동 추출됩니다. 스포이트를 켜고 미리보기의 사진을 클릭하면 해당 위치 주변의 색으로 다시 추출합니다. 팔레트를 누르면 배경색에 적용됩니다.
- **포커스 모션**: 클린/iPhone, 그리드/Galaxy, 프로/카메라 스타일, 가로·세로, 자막·색·기울임, 반복 여부, GIF 크기를 선택합니다. 원래 기기의 카메라 앱 화면을 복제하지 않고 독자적인 그래픽으로 표현합니다.
- 사진 위치 조정에서 확대와 가로·세로 위치를 변경할 수 있습니다.
- **PNG 저장**은 현재 디자인의 고해상도 정지 이미지, **GIF 저장**은 3.6초 모션을 생성합니다. 저장 후 다시 다운로드 링크도 제공됩니다.
- **공유**는 지원 브라우저에서 시스템 공유 창을 열고, 그 외에는 페이지 주소를 복사합니다. 이미지를 자동으로 SNS에 업로드하지 않습니다.

## 기능 대응

| 참고 기능 | SCENE 구현 |
| --- | --- |
| 사진 기반 음악 플레이어 배경화면 | 독자적 레이아웃의 뮤직 포스터 |
| 사진의 5색 팔레트 | 색상 분포 분석과 유사색 간격에 기반한 추출 |
| 연속 스포이트 | 사진 위치를 눌러 주변 색 재추출 |
| 배경색과 자동 글자 대비 | 밝기에 맞춰 밝은/어두운 텍스트 자동 선택 |
| 휴대폰 해상도별 PNG | 1080×1920, 1320×2868, 1080×2400, 1440×3200 |
| 카메라 3종 및 가로·세로 | 클린 / 그리드 / 프로, 9:16 / 16:9 |
| 초점 탐색, 잠금, 셔터 애니메이션 | 흐림·미세 흔들림·초점 표시·플래시·프로 셔터 |
| 자막 및 색상·기울임 | 줄바꿈 자막, 자유 색상, 기울임 |
| GIF 크기·반복 및 PNG | 긴 변 360/540/720px GIF, 긴 변 1920px PNG |
| 다시 재생, 업로드·드롭·붙여넣기 | 지원 |
| SNS 공유 | 시스템 공유 / 페이지 주소 복사로 통합 |

원본의 로고, 고정 제작자 서명, 샘플 그림, 안내 페이지와 다국어 UI는 가져오지 않았습니다. 편집기는 한국어입니다. 음악을 실제 재생하는 서비스나 실시간 카메라 촬영 앱이 아니라 **사진으로 결과물을 만드는 도구**입니다.

## 처리와 호환성

사진과 결과물은 브라우저 메모리에서 처리하며 서버로 업로드하지 않습니다. 새로고침하면 작업이 초기화되므로 결과물을 저장해 주세요. 사진은 최대 25MB까지 받으며 메모리 사용량을 줄이기 위해 내부 작업용 원본은 긴 변 4096px로 제한합니다. 움직이는 GIF를 입력하면 정지 프레임으로 사용합니다. HEIC는 보장하지 않으므로 JPG/PNG를 권장합니다.

최신 Chrome/Edge/Firefox/Safari를 대상으로 작성했습니다. GIF는 웹 워커를 사용하므로 파일을 더블클릭하는 `file://` 대신 GitHub Pages 또는 로컬 HTTP 서버에서 실행하세요. iPhone에서 자동 다운로드 대신 이미지가 열리면 다운로드 링크를 이용하거나 파일 앱에서 확인하세요. 실제 iOS/Android 기기 테스트는 별도로 필요합니다.

모션 줄이기 환경에서는 미리보기 자동 애니메이션을 정지 장면으로 보여 줍니다. 사용자가 요청한 GIF 저장에는 애니메이션이 포함됩니다.

로컬 확인:

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.

## 파일 구성

- `index.html`: 접근 가능한 편집 화면
- `styles.css`: 반응형 미니멀 디자인
- `app.js`: 이미지 처리·팔레트·캔버스·내보내기
- `vendor/gif.js`, `vendor/gif.worker.js`: 로컬 GIF 인코더
- `vendor/LICENSE-gif.js.txt`: GIF 인코더의 MIT 라이선스
- `.github/workflows/pages.yml`: 선택적으로 사용할 Pages 자동 배포
- `.nojekyll`: 정적 파일 전달 설정
